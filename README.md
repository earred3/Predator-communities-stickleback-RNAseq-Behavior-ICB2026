# Predator-communities-stickleback-RNAseq-Behavior-ICB2026
Code and supporting files for analyses of parental behavior and whole-brain gene expression in wild Alaskan threespined stickleback. Arredondo et al. 2026, ICB

This repository contains the code and supporting files used for the behavioral and whole-brain RNA-sequencing analyses associated with the manuscript:

#Predator communities with invasive pike are associated with changes in parental care and brain gene expression in wild Alaskan stickleback
https://doi.org/10.1093/icb/icag130

#Study overview

This study examines whether predator-community composition is associated with parental behavior and whole-brain gene expression in wild male threespined stickleback (Gasterosteus aculeatus) from southcentral Alaska.

Male stickleback were sampled from lakes representing different predator-communities, including communities with invasive northern pike (Esox lucius) and communities without invasive northern pike. Behavioral analyses evaluated paternal-care responses, and RNA-sequencing analyses compared whole-brain gene-expression patterns among predator-community types.

The repository includes:
- The R Markdown source file containing the analyses
- A knitted HTML version of the analysis
- Supporting sample data and metadata 
- R package and session information for reproducibility

#Sequencing data

Raw RNA-sequencing data are deposited in the NCBI Sequence Read Archive under:

BioProject accession: PRJNA1506108

The submission contains whole-brain RNA-sequencing data from 19 adult male threespined stickleback
